# Collabra 0.2.86

## 图标轨入口回归

- 关闭 Bot 功能后，标题栏不再保留只剩一个「Code」的分段控件，Code 入口回到左侧图标轨，
  排在图片工作台上方，鼠标悬浮显示「Code」，选中时用图标轨统一的底色与品牌色。
- 从设计画廊、图片工作台或扩展页点这个 Code 入口，直接回到 Code 对话，不需要先关掉当前页面。
- 协作看板的内容来自 Bot 任务，Bot 功能关闭后入口一并消失，图标轨不再留一个永远空着的按钮。
- Bot 功能开启时行为不变：Code / Bot 仍由标题栏中部的分段控件承载，看板入口保留。
  远程节点接管本机界面时两者都不出现，不暴露未启用的功能。

## 验收与更新范围

- 图标轨组件与工作模式入口的单测覆盖了新顺序与门控：Bot 关闭时 Code 在图片工作台上方、看板缺席；
  开启时图标轨不重复工作模式入口。
- 主题验收脚本的「Bot 关闭后的 Code」断言同步改为图标轨选中态，避免沿用旧的分段胶囊口径。
- 本次发布为 Mac arm64 同证书个人版，更新个人通道，不改变正式 Latest。
- 安装和重启由用户操作；发布成功不代表已经完成本机安装、旧数据保留或自动升级验收。
