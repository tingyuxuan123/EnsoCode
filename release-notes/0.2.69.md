# 小满 0.2.69

## 修复设计截图重复展示

- 批量校验多个设计画框时，聊天中只展示本次的一张总览图，不再同时加载每个画框的全部历史截图。
- 单帧截图默认只加载最新版本，点击「查看历史截图」后才加载旧版本；已有历史截图仍保留。
- 截图已被轮换清理或读取失败时结束加载占位，避免一直显示「截图中」。
- 兼容部分模型自动补齐的空可选帧参数，避免只请求批量截图却被误判为参数冲突。

## 工作台更名为「小满」

- 统一桌面界面、设置、托盘、安装包及手机端源码中的对外名称，并更新双语 README。
- Mac 应用显示为「小满.app」，下载文件使用 ASCII 前缀 `Xiaoman`。
- 保留应用 ID、运行时名称、数据目录、配对协议、GitHub 仓库和个人签名证书；Windows 可执行文件仍为 `Eaves.exe`，以兼容旧快捷方式。

本次仅发布 Mac arm64 个人更新通道，不改变正式 Latest；未包含工作区中其它未提交功能。安装、重启及旧数据升级验收仍由用户完成。
