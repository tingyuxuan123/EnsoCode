# CodeKiln 0.2.108

## 设计画布

- 恢复通过 Codemode 批量读取、修改或创建设计文件时的“浏览中 / 修改中 / 创作中”动画，保留扫描、流体背景和状态色效果。
- 同一项目中新建或切换会话时，发现已有设计稿只提供画布入口，不再自动展开、抢占聊天面板；主动从画廊、文件树或顶栏打开，以及新建设计，仍正常展开画布。
- 运行中重新打开、重载或弹出独立设计窗口后，只恢复尚未完成的活动，不重复播放已完成历史；操作成功后显示“已更新”，读取结束或失败后清理状态。
- 补丁活动识别兼容工具实际支持的参数形式，避免把正文示例误判为目标文件，并沿用输入大小限制。

## 聊天界面

- 修复工具卡片等容器中放大的图片预览被裁剪的问题，预览改为顶层浮层，保留点击和 Esc 关闭操作。
- 更新命令与技能托盘的分组列表、详情预览和窄窗口布局，优化项目计数、标签及选中项的主题色表现。
