# CodeKiln 0.2.99

## 记忆 Wiki

- 在主界面新增记忆 Wiki，集中浏览、搜索和编辑各个记忆空间的笔记，并在笔记之间沿链接跳转。
- 记忆笔记以本地 Markdown 文件保存；记忆空间可绑定已有的 Obsidian Vault，外部编辑会同步到搜索索引。
- 新增笔记体检，可发现断链、孤立笔记、陈旧草稿等问题。归档会保留笔记文件，不直接删除。
- **升级提示：**旧版 SQLite 记忆不会自动迁移，也不会出现在新版 Wiki 中。更新不会删除旧库；如需保留旧记忆，请在升级前备份。

## 助手记忆工具

- 助手可查阅记忆索引、搜索、读取、写入或归档笔记。Bot 写入共享记忆仍需人工审批。
- 支持按完整笔记 ID 精确读取；简称匹配到多篇笔记时会返回候选，不会猜测要读哪一篇。
