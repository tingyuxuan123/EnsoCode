# CodeKiln 0.2.88

## 新默认主题：Kettu 白 / Kettu 深色

- 新安装默认浅色 **Kettu 白**：纸白工作区坐在 `#f8f8f8` 桌面上，卡片与浮层同为白、只靠
  黑 10% / 16% 细线分层；文字 `#1f1f1f` / `#5c5c5c`；圆角按 Kettu 的紧几何 5 / 8 / 10，
  投影只给浮层与输入框。
- 深色换成 **Kettu dark**：侧栏 `#0e0e10` 比页面 `#141416` 暗一档，浮层与卡片 `#212124`
  比页面亮一档，靠明度分层而不是投影；描边是白色 12% / 18% 的细线。
- 新安装默认强调色改为「狐狸橙」`#f2581b`。已保存的浅色方案与强调色保持原样，只有缺失或
  非法值才回退到新默认。

## 选中块与图标

- 选中块（设置导航、会话行、分段页签、主题卡）改成中性的黑 / 白叠色加细线，橙色只留给发送、
  开关与复选、焦点环；和手机端的 `--ink` 叠色一致。
- 建议卡、模型选择器、思考档位、状态环节点等图标恢复墨色，不再整屏发蓝；没有内容可发时，
  发送键的橙色描边一并去掉。
- 设置 → 外观：深色外观下四张内置主题卡改用深色缩略图，不再在近黑窗口里摆一排白卡片。

## 文件行图标

- 本轮改动卡片与改动面板的文件行换成 Material 类型图标，与文件树、搜索结果、文件页签、
  产物卡同一套；改动状态仍由后面的字母与颜色表达，不给类型图标染色。

## 验收与更新范围

- `pnpm typecheck`、`pnpm lint` 干净，全量测试 14730 项通过；开发构建真机截图复核了浅色与
  深色主窗口、设置外观页与主题卡。
- 本次只改配色、线条与圆角这一层，不改布局尺寸；代码高亮、diff 与终端配色仍走各自主题系统，
  本次未改。
- 本次为 Mac arm64 同证书个人版，推进个人更新通道，不改变正式 Latest。
- 安装与重启由用户自己操作；发布成功不代表已在本机完成安装、旧数据保留或自动升级验收。
