# CodeKiln 0.2.102

## 协作者会话

- 可以在协作者会话中手动切换模型，切换后沿用当前会话的上下文继续工作。

## 设备操控

- 重构设备访问请求的处理流程，同一台设备上的待处理授权请求不再堆积，授权面板会跟随当前会话显示。
- 设备画面在丢失指针捕获或窗口焦点时立即释放触点，不再出现松手后仍继续拖动的情况。

## 记忆与知识库

- 记忆笔记改动以紧凑差异展示，在会话时间线里直接看到本次更新了哪些条目。
- 新增记忆写入的静态检查，能提前拦下格式错误、失效引用和重复条目。
- 启动时按需注入项目记忆提示，减少无关上下文占用；记忆来源代码变化后会标记为待复核。

## 安卓端

- 会话时间线新增工作状态行，能看清当前正在执行的步骤。
- 会话产物支持下载与用其他应用打开，图片可在时间线内直接查看。
- 桌面镜像连接更稳定，重连后会补齐会话与产物状态。

## 界面

- 补充和统一了一批界面文案。
