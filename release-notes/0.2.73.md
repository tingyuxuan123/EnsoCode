# 小满 0.2.73

## Windows 图片生成与编辑

- 在本地 Code 聊天及临时会话中生成图片，或按要求编辑工作区内和先前生成的图片。图片保存到工作区，可从历史记录恢复预览。
- 新增独立图片服务设置：API 地址、加密保存的 API Key、模型列表、连接测试及模型选择导入，不再要求先添加聊天模型服务。
- 支持图生图开关、分别选择生图与改图模型，以及跟随会话、1K / 2K / 4K、固定尺寸、质量和额外 JSON 参数；设置页可预览实际发送参数。
- 生成过程中显示 Vetta 同款黑白蓝流动占位动画、白色图标及“图像处理中”提示，图片加载后淡入。失败、停止及减少动态效果模式均正确收束。
- 图片右上角提供编辑、复制和下载按钮。编辑只插入草稿，不自动提交；复制成功就地显示对勾；下载保留原图格式，不重新生成。
- 修复“画一张海报”误走设计画布的问题：生成图片与可编辑画布明确分工，4K 16:9 图片请求使用 3840×2160。
- 保留尚未迁移的旧图片服务配置；显式保存独立配置后不自动回退旧服务或旧 Key。更换地址时清除旧凭证，避免误发。

## 验证与说明

- 本版为 Windows x64 安装包。CI 校验类型、lint、测试、包内原生依赖、设计引擎和下载资产哈希后公开发布。
- 已用 DeepSeek V4.1 Flash 与 GPT-6.1 Sol 在隔离 Electron 中验证生图工具调用和海报路由；图像端使用模拟服务，未验证具体付费图片供应商的响应或计费。
- Windows 实机安装、从旧版升级及旧数据保留尚未人工验收。发布成功不等于已经安装；请由用户正常安装和重启。
