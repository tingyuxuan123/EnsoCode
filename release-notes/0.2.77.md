# Collabra 0.2.77

## 代码搜索更可靠

- 云端响应中途断开时不再只报一句无法排查的失败：现在会明确归类为网络中断并自动重试一次，多数瞬时故障可直接搜出结果。
- 模型点到名字像密钥、或已被忽略规则排除的普通文件时，只跳过那一条引用，其余已验证的文件范围照常返回，不再整次作废。
- 越界路径、符号链接竞争和文件身份变化仍会让整次搜索失败，代码外发边界没有放宽。

## 代码搜索更容易被用上

- 模型在"准备第二次用关键词 grep 去找位置"时会改用代码搜索，而不是继续猜关键词。
- 代码搜索的一行说明改为优先推荐它定位不熟悉的代码，并提示一次调用可替代多轮 grep 加读取。
- 说明中要求尽量带上子目录，避免默认扫描整个工作区带来的等待。
