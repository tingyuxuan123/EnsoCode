# Collabra 0.2.85

## 浏览器操作更流畅

- 已经确定的连续步骤可以一次执行，减少点击、填写与等待之间反复请求模型的时间。
- 点击、填写和导航后直接返回页面变化与可继续操作的控件，不再要求每一步都重新读取整页。
- 支持定位前一步操作后才出现的输入框或按钮；结合页面变化和网络请求进行有界等待。
- 兼容模型补齐无关可选字段的调用，减少参数错误和回退为逐步操作的情况。
- 连续操作仍校验页面归属和导航权限；遇到失败、取消或人工操作立即停止，不自动重放已经发送的输入。

## 浏览器过程更清楚

- 浏览器步骤按操作次数和实际思考时长收拢，展开后显示“进入登录页、填写账号、填写密码”等简短动作。
- 不再直接展示内部工具名、引用编号、JSON 参数和整块协议结果，也不回显密码或输入正文。
- 旧会话没有动作描述时，使用操作类型和之前实际看到的控件名称显示摘要。
- 真实失败、尚未执行的步骤和需要核对的页面结果仍会明确提示，审批记录保留。
- 取消、超时或没有结果的中断不会声称“未执行”；无法确认的步骤标为“需要核对”，避免诱导原样重放。

## 验收与更新范围

- GPT 与 DeepSeek 均在隔离桌面环境完成真实浏览器验收：四个连续步骤一次执行，加上打开页面共两次工具调用。
- 已检查实际展开界面的动作列表，并完成桌面全量检查和手机端类型检查、构建。
- 本次发布为 Mac arm64 同证书个人版，更新个人通道，不改变正式 Latest。
- 安装和重启由用户操作；发布成功不代表已经完成本机安装、旧数据保留或自动升级验收。
