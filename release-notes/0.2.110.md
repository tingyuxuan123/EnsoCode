# CodeKiln 0.2.110

## 设计画布

- 恢复通过 Codemode 批量读取、修改或创建设计文件时的“浏览中 / 修改中 / 创作中”动画，保留扫描、流体背景和状态色效果。
- 运行中重新打开、重载或弹出独立设计窗口后，只恢复尚未完成的活动，不重复播放已完成历史；操作成功后显示“已更新”，读取结束或失败后清理状态。
- 同一项目中新建或切换会话时，发现已有设计稿只提供画布入口，不再自动展开、抢占聊天面板；主动从画廊、文件树或顶栏打开，以及新建设计，仍正常展开画布。
- 补丁活动识别兼容工具实际支持的参数形式，避免把补丁正文中的示例误判为另一个目标文件，并沿用工具的输入大小限制。

## 聊天界面

- 修复工具卡片等容器中放大的图片预览被裁剪的问题，预览改为顶层浮层，保留点击和 Esc 关闭操作。
- 命令面板改为独立浮层；更新命令与技能托盘的分组列表、详情预览和窄窗口布局，优化项目计数、标签及选中项的主题色表现。

## 插件工作区

- 原生插件页面可声明出现在最左图标轨，点击后作为独立工作区打开，不再只占右侧标签页。
- 工作区不创建对话，也不改变当前会话、侧栏宽度或折叠状态；切回 Code 即可继续对话。
- 停用或卸载插件会立即撤销入口和页面，不会留下空白标签；重新启用后插件自己的数据仍在。
- 后台会话不能把已打开的工作区改投到另一个项目，页面始终绑定打开它时的上下文。

## 插件界面跟随主题

- 插件页面不再只有浅色/深色两种标记，而是直接读取当前应用的背景、面板、文字、强调色、边框、圆角和字体、字号。
- 同一浅色模式下切换强调色、浅色调色板或插件主题也会立即同步，不需要重开页面，编辑中的草稿不会丢失。
- 只同步有限长度的外观令牌值，不向插件页面暴露任意 CSS、宿主 DOM 或网络权限，沙箱与内容安全策略保持不变。

## 记忆插件

- 附带「记忆」插件 1.0.1：长期记忆、每日日志、待办、可恢复删除、关键词检索与每轮上下文。
- 入口在最左图标轨，管理界面使用应用当前主题。
- 自动学习默认关闭，自动会话总结默认开启；启用后会用所选模型处理最近的对话片段，可能产生费用。

## 知识地图插件

- 附带「知识地图」插件 1.10.0：新增默认关闭的后台自动维护，每轮结束用一个只读代理调查源码并补充最多 3 篇 `llmdoc/*.md`，同时登记到 `llmdoc/meta.json`。
- 只写 `llmdoc/`，保留写入前的精确原文，可在侧栏「自动维护记录」逐条回退，不创建 Git 提交、不推进全局基线、不删除文档；已有文档只更新 front matter 并追加正文，不覆盖手写内容。
- 新增 `agent.run`、`fs.read`、`fs.write` 权限，范围仅限 `llmdoc/`；开启后每轮会产生一次模型调用费用，回退新建文档时会留下可手动删除的「已回退」占位。
