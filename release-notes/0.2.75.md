# Collabra 0.2.75

## 上下文与长任务

- 新增默认开启的保守微压缩：只清理较早的成功纯文本读取和搜索结果，保留最近五条；不调用模型，时间线和磁盘原文保留。
- 可在设置中关闭后续微压缩，并在上下文检查器查看当前分支清理的结果条数和字符数；关闭不会恢复已经清理的模型上下文，也不代表确定的费用或 token 节省。
- 模型因实际输出上限截断时，最多自动续写三次；截断的工具参数不会执行或重放。续写会产生额外模型请求，可能增加费用。
- 修复排队消息将仍在产出的回合误判为挂起的问题；远端单次流式请求新增不随持续输出重置的 60 分钟硬截止，本地推理不受此限制。
- 稳定工具声明顺序，放宽正常中文网页正文的内联预算，并在后台通知队列溢出时明确告知累计丢弃数量。

## 连接与记忆

- 远程连接的周期心跳连续两次超时才判定断开，减少短暂延迟导致的误断；手机网页兼容新旧连接接管关闭码，避免自动重连互相抢占。
- 恢复 BGE-M3 的 8192 token 原生上下文上限，减少长记忆被过早截断；超限时仅记录不含正文的诊断，不自动重建已有向量。

## 品牌与界面

- 内置助手、回复标题、召唤入口、设计批注和中英文文案进一步统一为 Collabra，保留原有授权身份、兼容标识和用户自定义名称。
- 云白配色调整为中性黑白灰，改善输入框、侧栏切换和选中态的层次，并完善品牌运行图标。

本次仅发布 Mac arm64 同证书个人更新，推进 personal-updates，不改变正式 Latest。
安装、重启及旧数据保留的真机升级验收由用户自行完成；发布成功不代表已经安装。
