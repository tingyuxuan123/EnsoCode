# 小满 0.2.70

## 新增「超级助理」

- 从桌面左侧图标轨打开固定入口。在一处交代多个本机 Code 项目的需求，超级助理会检索项目和会话，按需续用已有会话或新建会话派发。原有 Code 与 Bot 工作区保留。
- 目标会话忙时，任务排队等待，不会插话打断当前轮次。右侧「执行动态」显示等待处理、排队、执行和结束状态，可筛选、查看结果、停止任务或跳回原会话。
- 状态由实际投递和执行回执决定。「本轮已结束」不代表需求已经验收；应用重启不会自动重放尚未结算的任务。
- 首版仅支持本机 Code 项目，不含 SSH 项目、群聊任务、定时调度和复杂工作流。

本次仅发布 Mac arm64 个人更新版，不改变正式 Latest。安装和重启由用户自行完成。
