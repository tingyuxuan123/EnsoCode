# CodeKiln 0.2.112

## 插件工作区

- 左侧工作区（如「记忆」）顶部新增项目选择：可选全局、已添加的本地项目和隔离 worktree，不必先创建聊天；选项目后默认显示该项目＋全局，下方仍可单独筛选范围。切换只改这一页的查看与编辑范围，不迁移数据、不改变聊天会话。
- 有未保存编辑、或切换还在进行时，新增、编辑与发送会被拦下，避免草稿存到另一个项目。
- 项目标识由主进程按已登记记录推导，页面不能指定任意磁盘路径；隔离 worktree 各自独立，不会被合并。

## 插件会话注入

- 修复插件注入「显示成功但消息没到」的问题：消息命令不再携带多余字段，主进程要等到目标会话真实接收才算成功。
- 空白会话可以直接被插件启动（按会话自己的模型设置），有历史的会话正常恢复；不会塞入占位消息，也不改输入框草稿或当前选中会话。
- 会话退出、换代或接收超时会明确报错且不自动重发；会话正在压缩时拒绝注入，不会并发开新轮。

## 记忆插件 1.3.0

- 待办改为未开始 / 进行中 / 已完成三态，列表分组、按状态筛选，进行中排在每轮上下文最前。
- 待办可放图片：粘贴截图、拖入或选择文件，列表显示缩略图、点开看大图；图片只存本机私有目录，不进上下文包。
- 待办可直接发到本工作区的会话：带正文、原图和待办 ID，确认接收后标为进行中；Agent 完成后用工具勾选或改写正文，一轮回复结束不会自动算完成。
- 仅复制指令不再改变待办状态。单次发送最多 4 张 PNG/JPEG/WebP/GIF；超限或格式不支持时整条拒绝并保留原图。
- 本版申请 `agent.inject` 与 `session.read` 权限，更新时需确认；发到非当前会话还需在 扩展 → 记忆 打开跨会话授权。

## 说明

- 记忆插件需要同时更新到 1.3.0 才能使用项目选择与直接发送；只更新应用不会自动升级插件。
