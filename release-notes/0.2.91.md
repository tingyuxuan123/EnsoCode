# CodeKiln 0.2.91

## 手机端查看目录外的 read 图片

- 手机端此前只能查看工作区内的图片，工具把截图或生成图写到 `/tmp` 等会话目录外时，手机上只显示「图片没了」。现在这类图片也能正常显示。
- 目录外图片不再靠路径放行：手机只上报时间线里那次 `read` 工具调用的 id，电脑回到会话记录确认该调用成功，再按它记录的原始路径读取文件。
- 手机侧仍然绝不上行绝对磁盘路径；工作区内图片继续走相对路径，越界、软链逃逸、超大和非图片文件一律拒绝。
- 加载中与失败都有可见状态，断线时统一按失败处理并可重试；旧版桌面不下发该能力时，手机保持原有的纯文本回退。
- 补充了协议、Main 侧解析与手机侧去重的单元测试，以及配对图片链路文档。

## 验收与更新范围

- 本次包含 TypeScript、lint 与全量测试（14767 通过）。
