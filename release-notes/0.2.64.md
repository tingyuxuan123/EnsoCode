# EnsoCode 0.2.64

## 新功能

- **聊天排版**：在「设置 → 外观」分别调整正文、标题、表格、代码块和行内代码的字号与字重，可预览、恢复默认并随配置同步。默认样式不变，文件预览不受影响。
- **Code 会话多技能**：输入框可叠加多个 `/skill:`，按顺序展开；草稿、失败重发和回退会保留技能与任务正文。长技能链不会挤掉聊天中的任务正文。
- **模型中心**：可一次拉取全部供应商模型，各条目独立显示结果，单家失败不阻断其他刷新。
- **聊天网页链接**：默认用会话内置浏览器打开；按住 Ctrl 点击走系统浏览器，也可在「内置工具 → 浏览器」关闭。
- **子代理完成报告**：以 Markdown 展示正文，token、工具次数和耗时单独显示。

## 修复

- 修复已无运行实体的子代理关闭时可能留下标签页的问题。
- 修复界面缩放时内置浏览器与停靠 DevTools 的原生视图位置偏移。
- 修复 Windows 放大图片时原生窗口按钮区不随遮罩变暗的问题，并改进本地 PowerShell 版本相关提示。
- 修复 Windows 上设计引擎和设计稿跨盘时画框可能白屏的问题。
- 改进侧栏拖动反馈；从 Bot 忙碌条查看成员过程时，按状态加载实时会话或历史记录。
- 手机端不再把尽力而为的在线状态上报失败显示为命令错误。
