# CodeKiln 0.2.92

## 移动设备面板

- 标题栏的手机图标，或右侧面板的 ＋ → 移动设备，都能打开当前本地 Code 会话的设备面板：
  列出 Android 模拟器与真机、iOS 模拟器与 iPhone。选中即启动（已关机的模拟器会先开机），
  画面直接显示在应用内，不另开原生模拟器窗口。
- 画面支持点按、拖动、滚轮、文字输入，以及 Android 的返回、主屏幕、最近任务、锁屏、
  音量与旋转；上方可截图、录制最长 60 秒画面、切换浅深色，也能随时断开。
- 设备按会话归属，同一台设备不会被两个会话同时操作；在别的会话打开时点它会移过来。
- 环境准备收成一条折叠的检查：缺 Xcode、缺 Android SDK、USB 调试未授权都列出官方链接，
  CodeKiln 不代装、不接受许可、不代签名。

## 让 AI 操作设备

- 新增 device_* 系列工具：读屏（无障碍树）、点按、填字、滑动、硬件键、旋转、装/启/停应用、
  打开链接、看日志、改外观与定位等。
- 第一次操作某台设备前必须授权：拒绝、仅本会话允许、始终允许这台设备。
  等待授权期间输入框与消息队列会锁住，不会把没生效的话发出去。
- 授权在界面上随时可撤销；「始终允许」单独管理，可按设备收回。

## 界面

- 桌面排版对齐 Kettu：界面 13px、输入框 15px，等宽文字换成 JetBrains Mono，
  中文按平台字体的字重档位匹配，中间字重不再落到 Light。
- 工作区从贴边的实底块变成浮在外壳里的圆角卡片，四周留缝；Code、Bot、远程节点、
  图片工作台保持同一套外壳。
- 移动设备面板的空态重排：可启动的设备在前，环境检查退成页脚；
  设备行的状态改成「已关机」这类读作状态的短标签，不再像可点的关机按钮。

## 本次修复

- 截图与录屏真正落到下载文件夹：此前画面被丢弃还提示「设备主机未就绪」；
  录屏现在按 10 fps 拷贝画面，静止的屏幕也能录出可播放的 MP4。
- AI 打开设备时，面板会自己出现并选中那台设备，而不是只回一句「就在对话旁边」。
