# EnsoCode 0.2.54

- **独立协作看板**：点击左侧入口打开独立窗口，不再替换当前工作区；再次打开会唤回已有窗口，窗口尺寸和位置可保留。
- **直接管理任务**：可在看板中选择群聊并新建任务，按标题、详情或编号搜索，按群聊、执行人和待处理事项筛选；卡住的任务单独展示。
- **就地查看和处理**：点击卡片展开任务详情和历次执行记录，可直接编辑、指派、验收、退回或取消；需要查看完整对话时，返回原群并定位任务。
- **手机远程同步**：修复会话可能持续停留在“正在读取历史”的问题；已有缓存正文时，同步失败也会明确显示并支持重试，避免重试被突发请求去重吞掉。
- **界面说明**：将脚本编排入口从容易误解的“隔离沙盒”调整为准确的功能名称。

Windows x64 构建还包含此前 0.2.53 中的 Bot 设计交稿预览、跨群任务入口、扩展管理和更新日志改进。本轮 Windows 安装、旧数据保留及自动更新尚待实机验收，Windows 发布先保留草稿；Mac arm64 个人版按原证书独立发布，不改变 Windows Latest。
