# EnsoCode 0.2.53

本次 Mac arm64 个人版包含自 0.2.46 以来的桌面更新。

- **Bot 设计交稿**：私聊和群聊可在消息里预览设计封面、点击打开画布；支持视觉输入的模型可以截图并读图。内置设计技能在本地项目首轮发消息前即可从技能菜单选择。
- **协作看板**：左侧全局栏新增跨群看板，可按群聊或待处理事项筛选，并跳回原群定位任务。
- **扩展管理**：Code 侧栏新增扩展入口，集中管理技能、MCP 和插件；新增本地插件作者模板与静态校验，并隔离插件界面的局部异常。
- **更新体验**：查看当前更新版本的发布说明；关闭自动更新后仍可手动检查和下载。
- **工作台与稳定性**：改进薄荷白浅色方案选择器，工具输出显示系统提醒；改善知识图谱异常结果重试、向量检索同分排序及 Codemode 顶层工具提示，并加入按证据复核的审查预设。
