# Collabra 0.2.87

## 浏览器操作定位不一致

- 修复“快照里看得到登录按钮，批量操作却报 Target not found”的问题。快照、页面读取与
  批量操作现在共用同一套控件命名规则，覆盖 `aria-labelledby` 关联文字、提交按钮的
  value 以及输入框的 name。
- 「登 录」这类中文排版空格可以按「登录」定位，但仍优先完整精确名称；同一页出现多个
  同名控件时继续拒绝并要求用 role 或 nth 指定。
- 批量操作中途停止时，错误里会附带一次有界的当前页面和可用引用，方便直接接着往下点，
  不必先自己再取一次快照。

## 安全边界没有放宽

- 旧引用仍然不会被猜成新元素；失败信息里没有展示的引用也不能直接执行。
- 已填写或已点击的步骤不会自动重放，人工介入或取消之后也不会再追加读取页面。
- 密码输入框的值仍然不读取、不输出。

## 验收与更新范围

- 单测覆盖按钮 value、`aria-labelledby`、输入框 name、中文排版空格与歧义拒绝；新增的
  `browserHost.actions.test.ts` 验证旧引用不发送输入、失败反馈可用、中途停止不重放、
  人工介入后不再读取。
- 隔离 Electron 真实 guest 页面验证通过：三种登录按钮形态各完成一次账号密码填写与登录、
  旧引用被拒绝且返回的新引用可继续点击、批次中途停止只保留已完成的输入。
- 本次发布为 Mac arm64 同证书个人版，更新个人通道，不改变正式 Latest；同时提供 Windows x64 构建。
- 安装和重启由用户操作；发布成功不代表已经完成本机安装、旧数据保留或自动升级验收。
