# CodeKiln 0.2.90

## 聊天工作区精修

- 新会话欢迎页改为居中的工作台卡片，补齐品牌图标、面包屑、标题层级、细线与轻光晕，并让建议入口在宽屏下保持合适的阅读宽度。
- 欢迎面板、消息列和输入区统一使用 `860px` 阅读列，底部输入区与上方卡片左右严格对齐；展开右侧面板时仍会自动收缩并保持边界一致。
- 建议卡增加品牌色图标、箭头提示、轻微抬升与键盘焦点反馈，并兼容减少动态效果设置。
- 输入区使用更柔和的圆角和聚焦投影，用户消息气泡同步采用一致圆角。
- 运行状态改为紧凑状态卡，区分思考、写作和工具执行阶段；计时器按语言显示，并避免读屏器每秒重复播报整张状态卡。

## 工具栏与状态信息

- 应用更新进度从顶部整条横幅移到左侧图标轨，完成、下载和重启入口更集中，不再挤占聊天工作区。
- 上下文与运行统计改为左侧常驻位置加右侧轻量状态药丸，工作区选择器直接显示当前分支。
- 精简更新、统计和会话状态中的重复信息，并对齐审批档位与工具栏图标尺寸。
- 重画 macOS 菜单栏模板图标，修正小尺寸画布留白，同时更新九点加载动画。

## 验收与更新范围

- 本次包含 TypeScript、lint、全量测试与开发窗口视觉复核。
- 本次为 Mac arm64 同证书个人版，继续推进个人更新通道并发布为 prerelease，不改变正式 Latest。
- 安装、退出与重启由用户操作；发布完成不代表本机已经安装或完成旧数据升级验收。
