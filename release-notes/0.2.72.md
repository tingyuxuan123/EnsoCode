# 小满 0.2.72

## 聊天生图与改图

- 本地 Code 会话可以生成图片，也可以按要求编辑已有成图或工作区内的参考图。
- 在「设置 → 内置工具 → 图像生成」分别为文生图、图生图选用已添加的 OpenAI 兼容图像服务和模型。不需要 Vetta 订阅。
- 成图在聊天里预览；点击「编辑图片」把引用填入草稿，由你补充要求并发送。原图和新图分开保存在工作区的 `.xiaoman/images/`，重开聊天仍可查看。
- 提示词和参考图只发往配置的图片服务，调用可能计费，失败不会自动重试。

本次仅发布 Mac arm64 同证书个人更新版，不改变正式 Latest。安装和重启由用户自行完成。
