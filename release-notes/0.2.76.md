# Collabra 0.2.76

## 原生插件全面升级

- 插件可按扩展名接管文件查看器、在输入框底栏显示状态、给命令设置默认快捷键，并可在侧栏打开自己的页面、向页面推送事件。
- 插件可贡献 workflow 预设、子代理类型与插件预设；自建预设可叠加插件预设，模型、思考档位与更严格的审批档位会随预设生效。
- 新增全量事件与自动化接口：回合开始前追加本轮提示词、模型切换通知、会话状态订阅、按插件预设新建会话、向会话注入文本或图片、中止本轮，以及常驻进程里的定时任务。
- 插件工具可声明只读并回传进度，模型工具结果可附带产物文件；界面只拿产物标识，不暴露磁盘路径。
- 插件可提供主题（浅/深色调色板、可选素材与背景），只有用户显式选择时才覆盖当前配色；停用或卸载即恢复原有主题。

## 自己写插件更容易

- 新增 `pnpm plugin:pack`：复用安装校验打出可复现的 ZIP 并输出 SHA-256，不执行代码、不覆盖已有文件。
- 新增 `pnpm plugin:testing`：生成零依赖测试桩，可在插件目录直接 `node --test`。
- 新增 `pnpm plugin:validate` 之外的作者类型声明 `types/enso-plugin.d.ts`，`examples/plugins/starter` 同步更新。
- 插件可从文件夹安装后开启「开发模式」，改动保存即自动重装；扩大权限不会自动同意，必须手动确认。
- 支持 `enso://install-plugin?url=<https 地址>` 网页唤起安装，只打开确认预览，不自动安装或启用。

## 插件市场与更新

- 市场按分类展示，卡片网格与详情页可看截图、权限和说明；已安装插件与市场都可查看使用说明。
- 市场来源的未扩权更新可自动安装（默认开启，可关闭）；扩大权限的更新仍需单独批准，正忙时延后。GitHub 等其它来源只提示不自动安装。

## 安全与兼容

- 新安装的插件默认停用，安装预览不执行任何插件代码；插件登记表损坏时只读并备份，不会清空已有插件。
- 安装链接只接受 HTTPS，下载逐跳校验域名与地址；解压、符号链接与文件读写沿原有边界。
- 插件对本机会话的写入、MCP 调用与跨会话注入继续校验实时代际、Plan 状态与用户授权，子会话默认不能变更。
- 侧栏与文件查看器仍在 sandbox 框架内运行，配对协议、远程节点和 Bot 不接入本机原生插件。

本次仅发布 Mac arm64 同证书个人更新，推进 personal-updates，不改变正式 Latest。
安装、重启及旧数据保留的真机升级验收由用户自行完成；发布成功不代表已经安装。
