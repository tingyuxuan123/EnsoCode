# CodeKiln 0.2.109

## 插件工作区

- 原生插件页面可声明出现在最左图标轨，点击后作为独立工作区打开，不再只占右侧标签页。
- 工作区不创建对话，也不改变当前会话、侧栏宽度或折叠状态；切回 Code 即可继续对话。
- 停用或卸载插件会立即撤销入口和页面，不会留下空白标签；重新启用后插件自己的数据仍在。
- 后台会话不能把已打开的工作区改投到另一个项目，页面始终绑定打开它时的上下文。

## 插件界面跟随主题

- 插件页面不再只有浅色/深色两种标记，而是直接读取当前应用的背景、面板、文字、强调色、边框、圆角和字体、字号。
- 同一浅色模式下切换强调色、浅色调色板或插件主题也会立即同步，不需要重开页面，编辑中的草稿不会丢失。
- 只同步有限长度的外观令牌值，不向插件页面暴露任意 CSS、宿主 DOM 或网络权限，沙箱与内容安全策略保持不变。

## 记忆插件

- 附带「记忆」插件 1.0.1：长期记忆、每日日志、待办、可恢复删除、关键词检索与每轮上下文。
- 入口在最左图标轨，管理界面使用应用当前主题。
- 自动学习默认关闭，自动会话总结默认开启；启用后会用所选模型处理最近的对话片段，可能产生费用。

## 其他

- 补齐知识地图插件被测试引用的自动化模块，并修正其两处时序与断言问题。
