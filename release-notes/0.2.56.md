# EnsoCode 0.2.56

- **Bot 群聊新增「任务托管（本地）」**：在右侧「群信息」开启，默认关闭。在同一群的任意话题以任务编号开头发送补充，例如 `#3 只修 Safari`，可直接交回正在执行或等待答复的成员任务会话，不必重新分派。
- **任务异常提醒**：执行中断、缺少信息或长时间无输出时提醒处理。不会自动启动待办、代替审批或重放中断的命令；中断任务由人确认后再处理。
- **补充与交付更准确**：正文中的 `#2563eb`、`issue #12` 不会被误认成另一个任务。成功与失败混合的批次保留每项结果，失败项明确标注等待人工恢复；全部等待人工时不唤醒父会话。后台巡检会合并连续事件，减少无关历史读取。
