# CodeKiln 0.2.95

## 会话过程轨迹：步骤徽标、竖向轨迹与入场动效

- 工具、思考与分组的摘要行换成 22px 圆角图标徽标：运行中轻微呼吸，失败转红，
  悬停整行浮出浅底，chevron 不再完全隐形。
- 连续的过程步骤之间用一条安静的竖向轨迹串起来，相邻步骤行距收紧到 6px 级，
  正文与工作日志周围仍留宽松间距，长回合的过程区更像一条时间线而不是一叠句子。
- 只有回合运行中新到达的步骤播放入场动效；历史加载和向上滚动回看不会重放动画。

## 侧栏状态与加载状态

- 会话状态微标重新区分语义：运行是迷你 Enso 环，待审批是脉冲环，等待回答是问号徽标，
  失败是静态叹号，未读是绿点，空闲是与文字基线对齐的极细占位点。
- 加载胶囊重做成圆角药丸：环形光点按阶段变形，阶段文字切换时滚动替换并扫光，
  计时沿同一基线排列。

## 修复

- 侧栏分组下拉按钮反复闪烁：溢出判断改按外层可用宽度比较内容宽度，
  不再因为 ⌄ 自己占的宽度而反复显隐。
- 脚本编排（workflow）里失败的工具调用现在会显示出来，不再被折叠隐藏；
  补丁类工具的纯成功回执不再单独占行，但变更对比保留。
- 修复消息列表页脚重挂：跟随最新输出时底部状态条不再被反复卸载重建。

## 验收与更新范围

- 本次通过 TypeScript、lint、全量测试与桌面构建检查。
- 本次为 Mac arm64 同证书个人版，继续推进个人更新通道并发布为 prerelease，
  不改变正式 Latest。
- 安装、退出与重启由用户操作；发布完成不代表本机已经安装或完成旧数据升级验收。
