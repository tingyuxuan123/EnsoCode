# CodeKiln 0.2.96

## 聊天区宽度可切换

- 聊天卡片顶栏右侧新增宽窄切换按钮：在阅读宽度与全宽之间切换，选择记进设置，
  立即作用于当前会话，重启后保持。

## 状态栏的项目名变成工作区菜单

- 底部状态栏里的项目名不再只是文字标签，点开就能看到并切换会话的工作目录。
- 临时会话走同一套菜单；远端项目仍单独显示主机标签，本机项目不加多余提示。

## 欢迎页与更新提示

- 空会话欢迎区重新排版：建议入口更紧凑，悬停与键盘可达性补齐，并补上回归用例。
- 更新弹窗重做：图标与按钮层级更清楚，更新日志、下载与「重启以更新」不再挤在同一行，
  浮层阴影与间距跟其它卡片一致。
- 补齐更新相关文案的中文翻译，不再有中英混排。

## 验收与更新范围

- 本次通过 TypeScript、lint、全量测试与桌面构建检查。
- 本次为 Mac arm64 同证书个人版，继续推进个人更新通道并发布为 prerelease，
  不改变正式 Latest。
- 安装、退出与重启由用户操作；发布完成不代表本机已经安装或完成旧数据升级验收。
