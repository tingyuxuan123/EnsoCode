# Collabra 0.2.74

## 全新品牌

- 产品正式更名为 Collabra，桌面端、手机端与文档统一使用新的蓝紫渐变图标和品牌名称。
- 保留原有应用标识、数据目录、配对协议、签名证书和更新通道；Windows 保留兼容旧快捷方式的可执行文件名。

## 独立图片工作台

- 新增独立图片会话，可直接生成图片、导入参考图改图，并查看和管理本地生图历史；不占用 Code 聊天会话。
- 支持模型、比例、分辨率、质量和 1–10 张批量生成；每张生成后即时保存和展示，取消时保留已有结果。
- 生成过程复用聊天生图动效，支持图片预览、复制和下载；草稿与参考图不会被迟到回包清除。
- 独立图片服务统一管理连接和模型，凭证加密保存在本机，不借用聊天凭证；失败不自动重试，每张图片请求可能计费。

## 交互与兼容

- Code、图片工作台、设计、Bot 与看板入口统一整理，切换到图片工作台不丢失已有会话。
- 本次同时发布 Windows x64 正式更新和 Mac arm64 同证书个人更新；Windows 推进 Latest，Mac 个人版仅推进 personal-updates。

安装、重启及旧数据保留的真机升级验收由用户自行完成；发布成功不代表已经安装。
