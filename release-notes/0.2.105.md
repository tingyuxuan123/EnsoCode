# CodeKiln 0.2.105

## 输入框与命令

- 输入框的斜杠命令改为分组托盘：系统内置、会话命令、项目技能分开显示，可继续输入筛选，直接填入命令或提示词。
- 新增 `/image` 与 `/plugin` 两个内置入口，分别引导生成图片和制作 CodeKiln 插件。
- 移除旧的预设（preset）体系，包括设置页、能力目录与提示词相关选项；遗留预设不再影响新会话。

## 扩展与插件

- 扩展页改版：新增插件制作入口、插件市场来源刷新，以及示例插件的图文说明页。
- 插件制作：在本地 Code 会话中生成插件草稿，先审阅文件与权限，再安装本地副本；草稿与工作区绑定，切换工作区后需重新打开入口。
- 新增「权限与数据访问」页，按声明的宿主 API 权限分类展示已安装插件与更新候选的风险项。
- 项目知识地图示例插件支持从改动源码反查需要复核的文档，并保持只读检查。

## 设计

- 设计系统详情页展示作者信息，网格页改为悬停/聚焦时按需加载演示预览与封面缓存。

## 其他

- 清理仓库内已废弃的设计稿工程与无用依赖。
