# CodeKiln 0.2.111

## 插件制作

- 制作的每个环节都要你逐项确认，不再由「运行静态校验」一个按钮替代验收。
- 填写需求后按用途推荐四种模板：左侧独立工作区、右侧辅助面板、仅快捷命令、仅模型工具；生成的 `HOST-CAPABILITIES.md` 记录当前这份代码实际支持的 API、权限与信任边界，不按版本号猜测旧安装版功能。
- 源码留在当前项目，Main 在私有目录记录制作项目、源码身份与验收记录；重启后在同一项目选「恢复插件制作项目」，不自动恢复任意移动或替换过的目录。
- 已安装插件可「继续修改已安装插件」复制源码到当前项目，保留永久插件 ID；不复制正式插件的私有数据与配置，也不自动升级或发送模型请求。
- 验收证据拆成静态、自动化测试、试用运行、业务流程、双厂商模型工具五层，全部绑定源码指纹；源码变化后旧证据标记过期，静态通过不会点亮其它层。业务与双厂商结论标注为「用户自报」，不是应用自动验证。
- 「运行插件行为测试」需单独确认，在源码快照中执行本地 Node 测试，剥离模型供应商、MCP 等凭证环境并使用临时 HOME；这不等于限制 Node 的磁盘或网络访问，测试仍只应运行完全信任的代码。
- 试用使用单独的 trial ID、配置和数据目录，「打开已安装的试用副本」会核对是否为最近预览的源码；「结束试用」只卸载试用副本及其测试数据，保留项目源码与正式插件数据。
- 交付是显式动作：导出 ZIP 走系统保存对话框并显示 SHA-256，不安装不发布；正式安装保留永久 ID 与已有数据，更新需递增插件版本；可预览上一版代码，但不会回退已迁移的数据，升级前请自行备份。
- 新增开发验收脚本 `scripts/verify-plugin-authoring.mjs`，默认不联网、不调用真实模型，需显式设置环境变量才执行受信测试或真实模型验证。

## 记忆插件

- 「记忆」插件更新到 1.1.3：整页按当前主题重做，长期记忆、检索、每日日志、待办、回收站、设置与编辑器统一为一份可浏览的界面。
- 新增「本轮上下文账本」：右栏显示下一轮真正会装入的那一包，含预算堆叠条、每段的条数与字数，以及被条数上限挡掉的条目，可一键复制整包。
- 回收站按批次显示来源与最多三条预览，删除后可恢复；带条数上限时优先保留置顶记录。

## 其它

- 扩展页的制作入口按上述流程重排，权限与数据边界的说明写在对应步骤旁。
