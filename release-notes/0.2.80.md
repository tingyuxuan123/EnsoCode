# Collabra 0.2.80

## 工作台布局更紧凑

- Code / Bot 模式切换统一放到标题栏中央，移除图标轨中的重复入口及重复会话标题。
- 优化会话页签的样式与横向滚动，页签较多时可用滚轮浏览。
- 左侧栏底部将节点切换与归档数量合并为一行，移除全宽的本地工作区、空闲和静态数据提示栏。
- 全局运行中、待处理会话数和远程不可用提示移到图标轨，侧栏收起后仍能查看。

## 会话用量摘要

- 输入框下方默认只显示输入 / 输出 Token、缓存命中率和上下文占用，不再重复模型选择器的信息。
- 已启用的统计项稳定显示，不再悬停展开挤动布局；窄窗口支持横向滚动，设置入口保持可见。
- 上下文使用随字号缩放的细进度条，接近上限时提示警戒色；未知窗口不编造百分比，点击仍可查看上下文详情。
- 仅将旧默认布局升级为三项统计，保留用户自定义开关、排序和全部关闭的选择。

## 插件入口分工

- 设置中的“插件”更名为“Claude Code 插件”，只保留 Claude Code 已安装插件的扫描、整包开关和组件详情。
- 原生插件统一从主侧栏“扩展”管理，移除设置页重复的安装、市场和更新区域。
- “获取更多主题”、原生插件通知与旧安装深链改投主界面扩展页，继续使用原有安装预览和插件详情定位。

## 外观、画廊与图片工作台

- 外观设置使用统一的内置 / 插件主题预览卡片，并集中展示个性化设置。
- 调整深色方案、强调色和选中状态，让浅色方案与背景图模式下的界面表现更一致。
- 设计画廊接管主工作区，不再留下项目侧栏及拖拽留白；返回 Code 后保留原侧栏偏好。
- 图片工作台移除重复的通用工作区行，增加分栏展开 / 收起动画，保留生图历史入口。

## 修复与兼容

- 修复 Bot 成员模型切换可能被后续思考档位更新覆盖的问题，资料保存 / 放弃操作在小窗口和大字号下保持可见。
- 修复 WPS 国际分享编辑器重复静态资源路径的兼容问题，并改善内置浏览器视图层级、布局与侧栏焦点保持。

## 个人版发布范围

- 本次发布到 Mac arm64 同证书个人更新通道，不改变 Windows 正式 Latest。
- 安装、退出与重启由用户操作；发布完成不代表当前安装版已经升级。
