# Collabra 0.2.78

## 目标执行步骤可查看

- 目标条新增“步骤”入口，点击目标文字也能打开执行详情，不再只有一个进度数字。
- 展示实际执行的目标启动、恢复和自动续跑轮次，包括状态、回复摘要；展开一轮可查看完整回复与工具操作、文件路径或命令摘要。
- 明确区分“自动续跑上限 25 轮”和任务清单，不生成尚未执行的未来步骤；暂停、受阻等状态也保留轮数。
- 支持加载更早的历史轮次；恢复后的轮数与尾窗编号正确对应，同名新目标和不同会话的详情互相隔离。
- 同步兼容手机端共享组件与历史补读。

## Windows 发布说明

- 本次仅发布 Windows x64 NSIS 安装包，不构建 Mac 或 Linux，不改变 Mac 个人更新通道。
- CI 校验安装包、原生依赖、内置设计引擎及远端下载资产的哈希，通过后公开并设为 Latest。
- Windows 真机安装、旧版本升级和旧数据保留尚未人工验收；CI 成功不代表已经在你的设备安装或升级。
