# Shell 调度与截止

本契约属于 agent worker 的进程生命周期，不是 Renderer 的超时策略。适用于
`bash` / `powershell`；前台移交使用同一进程、同一输出流，不重新执行命令。

## 让位与截止是两件事

- **让位**是结束这一次前台等待，把还在执行的进程交给后台任务管理器。
  按 RTK 改写前的原命令保守分类：常驻服务 10 秒，构建 / 测试 / 安装 180 秒，
  其余 45 秒。无法确定的命令归普通类；不是完整 Shell 解析器，也不是权限判定。
- **截止**只由显式 `timeout`（秒）指定；未指定就没有进程截止。
  `background: true` 同样接受截止。无效或超出计时器范围的值在执行前拒绝。
- 截止早于或等于让位时，只设截止。手动转后台、用户插话和自动让位均保留原绝对截止，
  不取消截止，也不从移交时重新计算整段时长。
- 后台配额仍为 10。自动移交失败时，有显式截止的命令继续留在前台直到原截止；
  没有显式截止则受控停止，并返回 `yield_failed`，不能误称已转后台或正常超时。
  用户手动移交失败不改变原执行状态。

任务回执明确说明进程仍在执行，并提供任务 ID、日志位置和下一步；让位不是 `timeout`
失败。只要任务仍在执行，就不应根据前台工具结束自动重跑或反复轮询。

## 所有权与收口

前台拥有让位和截止计时器；成功移交后，后台管理器接管同一个绝对截止。
进程退出立即撤销截止，再做 RTK 统计等异步收尾。不能在统计尚未完成时把已退出的
成功命令改成超时或用户停止。截止、用户停止、模型停止的首个原因生效，迟到操作不能覆盖。
主动停止不添加“命令失败、修复后重跑”的分类。截止命中后，即使程序捕获终止信号并
以 0 退出，完成通知和 `task_output` 也优先说明截止原因，真实退出码仅作诊断。
结束后到达的传输输出不得更改权威结果或重新写入已关闭日志；日志 I/O 失败不影响进程结果。

前台下一收口时刻经既有 `tool-output.deadlineAt` 投影，用于静默巡检；它是
`min(让位, 截止)`，不是进程必然被杀的时间。配额满而继续留在前台时，必须同步实际截止，
不能按已经失效的让位时刻判断卡死。结束事件仍由权威进程结果驱动。
刷新使用 SDK 最近一次已截断的可见快照，不能用内部原始缓冲覆盖它；移交失败结果保留有界输出。

## 展示与权限边界

失败分类用于解释截止、非零退出、缺失程序、终端 / 认证要求等；经白名单进入历史和
时间线，不放行任意 `details`，也不携带自动重试或审批豁免。成功命令打印错误示例不算失败。
RTK 的原命令、统计及清理仍使用已有路径。

本地非交互环境沿用 `hardenedEnv`，SSH operations 和传输包装不套用该环境覆盖。
SSH 截止只能保证终止本地传输客户端，不承诺远端进程树已经退出。
终止沿用进程组 SIGTERM / 宽限后 SIGKILL；逃离进程组并持有标准流的守护进程不在本项保证内，
显式后台任务仍需等传输关闭才能完成收口，不承诺对这种情况强制结算或自动重跑。

不改变 `task_output` 的 10 分钟单次等待上限、子代理默认 5 分钟 / 最长 10 分钟的等待、
任务完成通知规则或后台配额；不引入全局 Shell 设置、自动重跑或新的 IPC。

## 回归与验收

`foregroundCommand.test.ts`、`backgroundTasks.test.ts`、`rtk/rtk.test.ts` 覆盖计时器所有权、
移交 / 配额回退、统计在途、主动停止和迟到输出；`shell/policy.test.ts` 覆盖引号、注释、
here-document、关闭 watch 的参数与 PowerShell 调用运算符。`projection.test.ts`、
`shared/types/agent.test.ts`、`timeline.test.ts` 和终端输出组件测试覆盖展示白名单与下一步。

隔离 macOS Electron 的真实基线中，8 秒截止的命令手动转后台后仍在第 13 秒写入文件；
修复后在原截止终止，未发生迟到写入。DeepSeek 验证服务类自动让位，OpenAI 验证手动移交，
均按 Main 权威历史及独立文件副作用核对只执行一次；受控模型验证显式后台截止和前台失败标签。
这不是 Windows / PowerShell 或真实 SSH 服务器的真机验收；这些路径只有逻辑、包装和模拟进程覆盖。
