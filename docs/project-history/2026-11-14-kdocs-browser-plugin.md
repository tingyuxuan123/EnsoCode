# 金山文档需求插件 v0.1.0：浏览器试用版

## 范围与实施差距

用户为个人，明确放弃企业开放平台申请，选择浏览器操作，并在完善插件系统后要求开始实现。新增插件位于 `examples/plugins/kdocs-tasks/`，不使用令牌/Cookie/私有调试连接。

更新后的插件已支持侧栏、工具、预设和会话自动化，但仍没有公开浏览器入口。因此本次除插件本身，还补齐 `browser.control` + `browser.domains` 的受限宿主桥，复用现有插件进程帧协议、Main会话权威和BrowserHost；没有新增通用IPC/preload入口。首版不申请派发、常驻、调度和会话注入权限。

## 交付行为

- 配置文档、工作表、负责人、列映射、状态和最多50行的扫描范围。
- 默认不连接、不轮询、不写入；先人工连接和已知文字格校准。
- 显式开启测试副本写入后，再验证指定空白格“写入、读回、清空、读回”。
- 领取和交付分别展示字段预览，确认令牌单次使用；重新连接撤销旧预览及写校准。
- 需求按文档+工作表+唯一编号识别；负责人不变，只改状态、备注、测试列。
- Agent只有 `get_task` 与 `build_report` 两个只读工具，候选报告不自动回填、不自动验收。
- 写入意图先持久化，失败进入unknown；显式核对只读，不补写。部分成功/冲突阻断项目；确认全未应用后允许人工重新预览。历史记录有界，损坏文件不覆盖。

## 复核与回归

本轮补了实质边界的复现测试：

- 空值必须保留；截断必须显式标记，不能拿400字前缀覆盖完整备注。
- 同域另一份文档，即使工作表名与需求内容相同也拒绝沿用原授权。
- 导航结果返回本次固定目标tab，不能在await后读共享当前指针。
- 排队前和队列实际执行/输入时复查会话与URL，防止事后拒绝却已经发出Enter。
- 新领取不能继承上一轮报告，旧候选和旧确认不能跨执行复用。
- 不输出公式/多格粘贴，既有人工备注和测试记录只追加。

## 尚未验收 / 不代表已交付上线

- 没有自动安装、启用、发布市场、重启用户dev或更新安装版。旧版宿主仅装ZIP不一定支持新权限，当前源码须重启Main/pluginHost。
- 本轮未完成真实金山/WPS页面的列映射、编辑器完整值与服务端写回校准。先前测试分享页加载不稳定，本轮没有绕过登录或向正式表试写。
- 尚未完成两个不同厂商真实模型的自主工具验收，不能用假provider、模型单测或夹具冒充。
- 浏览器操作没有原子条件更新，不能保证多人并发排序时恰好一次或完全不写错行。仅适用于无人同时操作的测试副本，富文本/合并/保护格及多行文本不在首版适用范围，不能声称自动识别所有格式。
- 原生OS焦点、IME及长时运行不由本地表格夹具覆盖。

因此目前为**可安装源包的试用版，不是生产验收完成版**。实际使用必须先完成测试副本门禁；正式需求表的写权限和完整验收另行确认。
