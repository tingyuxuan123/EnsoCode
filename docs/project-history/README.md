# 项目历史资料

这里保存从旧任务记录和开发日志中迁出的设计、研究、验收与排障资料。

- `09-03-*`、`09-08-*`：迁移时尚未结束或仍被源码 / 文档引用的任务资料。
- `archive/`：按月份归档的历史任务（当前有 `2026-08`、`2026-09`）。
- `YYYY-MM-DD-*.md`、`*.html`：按日期命名的设计、研究、验收和原型；`2026-10` 起包含 Bot、代码搜索、插件移植等主题。
- `development-journal-*.md`：开发会话日志（若存在）。

这些文件只作为历史参考，不参与开发流程，也不要求按历史任务格式继续维护。新的长期约定应写入 `AGENTS.md` 或 `docs/engineering-guidelines.md`；高代价陷阱和分层规范位于 `docs/engineering-reference/`。
