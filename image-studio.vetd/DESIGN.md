# 图片工作台（image-studio）设计契约

> 本文件的约定优先于设计技能默认值。早先的「联系印样室 / 纸色档案」方向已作废，
> 以本文件和 `frames/` 里的实现为准。

## 定位

聊天式图片工作台：左边是会话，中间是「问候 → 对话与成图」，底部一条输入框，
图片旁边按钮打开参数弹窗，右上角「宫格」展开生成历史。不是画廊，也不是档案室。

## 颜色与字体来自小满本体，不另造一套

- `theme.css` 只做一件事：把小满 `src/renderer/styles/globals.css` 的语义 token
  映射成 Tailwind 颜色（background / foreground / card / popover / primary /
  secondary / muted / muted-foreground / accent / border / success / shell / panel）。
- 默认值取「晴空碧海 ocean-light」；`.dark` 取「远山暮霭 ocean-dark」。
  换肤时只换 token，不改布局与尺寸。
- 界面里不出现写死的色值、渐变、摄影质感的背景或自定义强调色。
- 字体：`Inter Variable` + PingFang SC（与小满一致），不引入第三套字体。
- 圆角：控件与卡片 6px，气泡与浮层 12px，输入框与对话框 16px，圆形另计。

## 结构：先有小满的壳，再有工作台

整窗尺寸即设计稿尺寸（1440×900），从上到下、从左到右：

1. **标题栏 44**（透明、无下边框，照 `TitleBar`）：红黄绿三颗窗口按钮（内容从 84 起）、
   左侧 `小满 工作台` 12px，中间是会话名 13px + 项目胶囊 11px，右侧两个面板开关。
2. **图标轨 56**（与 `AppRail` 一致：36 按钮、19 图标、gap 8）：`满` 字标、收起侧栏、分隔线、
   对话 / 图片工作台 / 设计 / 看板；底部询问 Enso（`text-primary`）与设置。
   当前项沿用真实写法 `bg-accent text-foreground`。
3. **侧栏 296**（右边一条 `line` 细线）：这是**独立会话模块**，不出现「项目 / 对话」分段、
   `新建任务`、`扩展`、项目范围条与项目分组——那些属于 Code 的项目侧栏。
   只放模块自己的对话：`对话` 标题 + 搜索按钮、`新建对话` 行（`circle-plus` 用 primary）+ `⌘N`、
   `最近` 排序、会话行（图标 + 标题 + 张数）、底部本月用量。
4. **主区**：44 高的标签条（照 `CoworkerTabs`：下边框 + 13px 页签，选中是 2px `primary`
   下划线，不是胶囊）—— `主会话`、`图片工作台 ×`、`+`，右侧模块状态胶囊「准备就绪」。
   右侧面板开关只保留标题栏右上角那一个（`panel-right`），展开即生成历史；
   不再在标签条里重复放「宫格」。
5. **底部状态栏 24**（照 `StatusBar`）：本地工作区 + 3 个运行中 + 数据留在本机。
6. **工作台内容**（标签条之下）：空状态是问候 + 示例提示 + 输入框；对话态是
   左右气泡 + 成图卡，底部同一条输入框。

成图卡照 `GeneratedImageCard` + `shared.css` 的 `.imagegen-*`：
图本体 `max-h 256`、`max-w 32rem`、`object-contain`、圆角 12、1px `foreground/10` 边；
**右上角 6px 处的三个 32×32 半透明按钮**（编辑 / 复制 / 下载：`bg black/42`、白 90%、
`backdrop-blur 12`、圆角 8、16 图标），桌面端悬停或聚焦才出现，触屏常显。
**没有**图下的「参数 / 改图 / 下载」文字行，也**没有**尺寸说明行——参数入口在输入框那一排。

两处有意保留的「评审会报」的写法，因为产品现状就是这样：
1. `backdrop-filter: blur(12px)` 的悬浮按钮（审查规则叫 tell-glass）。这是
   `shared.css` 里 `.imagegen-action` 的真实写法，不是新加的效果。
2. 稿里三个悬浮按钮常显；真实桌面端是悬停/键盘聚焦才淡入（触屏常显），
   静态稿常显只是为了让评审看得见。

输入框：card + border + 16 圆角。上排只有提示词；下排照 Code 输入框那一排，
左边是附件、「画图」入口（打开画图设置）、张数、提示词，右边是可点选择器
`模型 ▾` 与 `档位 ▾`（打开同一张画图设置）、`已用 / 上限` 和发送圆钮。
模型与档位不再写成输入框右上角的一行灰字。

## 两个浮层

- **画图设置**（`components/SettingsSheet.tsx`）：720 宽、16 圆角、popover 底；
  数量 / 比例（含比例小图形）/ 模型 / 格式 / 分辨率 / 质量；选中态用 `primary` 淡底 + `primary` 字；
  页脚左侧写默认值与「每次调用计费一次」，右侧「完成」。
- **生图历史**（`components/HistoryPanel.tsx`）：右侧是一个独立的**面板**，不是抽屉。
  它和主区一样有自己的 44 高标签条（同样的下划线页签），这条里只有一个页签
  `生图历史 ×`（关闭即收起面板），
  不再在标签条下面重复写「生成历史」标题和关闭按钮。页签下面是
  「全部 / 文生图 / 改图」筛选 + `28 张 · 按时间`，再下面是 2 列宫格缩略图与实发尺寸。

## 必须保持的产品事实

一次调用只出一张、300 秒、失败不自动重试、每次可能计费；原图不被覆盖，
改图是新文件并带父图；成图落在会话工作目录 `.xiaoman/images/<UUID>`。

## 素材说明

成图示例用的是占位照片（素材库只提供照片源）。真实实现里这一格是用户自己的成图；
若要换成插画或占位色块，只替换 `assets/` 与 `components/data.ts` 的 `src`，不动布局。
