## 精修（2026-11-04）

正式样式 `src/renderer/styles/mintLight.css` 已在上述基础上精修，仍只换肤、不改布局：

- 灰阶与绿色统一到同一色相（OKLCH h≈155）；`--accent` 改为中性，悬停、徽标、搜索按钮不再泛绿。
- 绿色只留给发送、当前选中、运行/完成状态：分组「全部」改为浅薄荷标签，模型选择、新建任务与「询问 Enso」恢复中性。

- 发送键空闲时为中性灰，有内容才亮起深绿；输入框聚焦改为浅绿边加柔光。
- 圆角三档 8 / 12 / 16（行与控件 / 浮层与气泡 / 输入框与对话框），菜单、弹出层、对话框带同源投影。
