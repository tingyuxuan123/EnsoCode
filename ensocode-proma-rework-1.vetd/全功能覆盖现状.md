# EnsoCode 全功能 UI 重构 · 现状

## 结论

设计稿覆盖当前 EnsoCode 的全部功能界面：Code 工作台与运行条、右侧停靠面板七类视图、设置窗口 21 个分类及主要子流程、Bot 模式、远程节点、手机伴侣、首次引导与系统状态。共 96 张可点击画布帧（外加一处共享布局路由），对应清单 90 个验收单元。

这是**设计稿**，不是真机验收：真实应用代码未改动；每项仍要在应用里逐条核对行为、状态与权限边界。

## 与上一版相比的改动

- 外壳改成按路由换壳：设置是独立 960×680 窗口，Bot / 远程各有自己的侧栏，手机是 390×844 独立布局。
- 去掉首版虚构的入口（项目管理页、运行控制页、改动审查页、检查点、头像工作区、全功能清单按钮），改回源码里的真实入口。
- 「运行控制」从独立页改回输入框上方的运行条，并按源码补齐提问、计划、目标、插话队列、项目信任、自动重试、模型阻断。
- 任务栏从两项补成三项（后台 Bash / 后台 Agent / 当前进度）。
- 右侧面板从固定三标签改成 dockview 式停靠面板，七类视图分别设计并各有状态帧。
- 设置从一页扩到 21 个分类，含模型中心向导 / 编辑 / OAuth / 账号池 / 虚拟模型 / 导入，以及记忆图谱、工作流设计器、用量与资源。
- Bot 模式从「协作页签」扩到成员、群聊话题、看板、委派、例程、收件箱、记忆、交付物、模板。
- 补上首次引导 8 步、OAuth 登录、更新横幅四态、退出确认、通用状态集合。

## 仍是演示数据 / 未做

- 会话、代码、Diff、用量、费用、成员预算都是示例数据。
- 不连模型、不执行命令、不写真实配置。
- 真机验收（含两个不同厂商模型的工具调用验证）尚未进行。
- 手机设计稿只做 390×844 一种尺寸，横屏与平板未覆盖。
